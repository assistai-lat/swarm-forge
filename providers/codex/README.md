# 🏗️ OpenAI Codex / Operator — Adaptador Swarm-Forge

> **Estado:** Cascarón preparado para desafío y generación autónoma.

Este directorio está reservado para la implementación nativa del estándar Swarm-Forge adaptado a las herramientas y modelos de **OpenAI (Codex / Operator / Swarm SDK)**.

---

## Cómo Ejecutar el Desafío

Cuando inicies una sesión con el agente o CLI de OpenAI en este repositorio, indícale la siguiente instrucción:

```text
Lee el archivo providers/codex/BOOTSTRAP_PROMPT.md y ejecuta tu misión para implementar el adaptador nativo de Swarm-Forge para el ecosistema OpenAI.
```

El agente de OpenAI leerá la especificación universal en `/spec`, estudiará el adaptador de referencia dorada de Antigravity en `/providers/antigravity`, y generará los archivos nativos correspondientes (`codex.json`, `.codex/`, configuración de modelos o3-mini/gpt-4o y scripts de orquestación).
